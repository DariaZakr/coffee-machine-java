# Coffee Machine Simulator

A small Java console project built as part of my Java studies.

The project uses classes to represent a coffee machine and coffee products.

## What I practised

- Creating Java classes and objects
- Using constructors, fields, and methods
- Working with coffee properties such as water, milk, coffee beans, and price

## Technologies

- Java

## How to run

Open the project in IntelliJ IDEA and run `CoffeeMachine.java`.
